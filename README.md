> **The Operating System for Creator-Led Marketing** — Connecting creator discovery, multi-platform social scheduling, product seeding drops, content approval, revenue attribution, and AI marketing intelligence into one unified connected platform.

---

## 🌟 Key Features

- **Dual-Audience Dynamic Interface**: Seamless toggle between **For Brands & Agencies** (AI Discovery, Product Drops, ROI Attribution) and **For Creators** (Free Lifetime Scheduling, Passport Profile, Wallet & Payouts).
- **AI Natural Language Creator Matching**: Query the engine in plain English (*e.g., "Find UK modest fashion creators 10k-50k followers"*) with verified 0-100 Creator Passport Scores.
- **Product Seeding & Voucher Drops**: E-commerce store drops (Shopify, WooCommerce) with voucher allowances, checkout top-ups, and deliverable tracking.
- **Campaign-Aware Scheduler**: Multi-platform publishing calendar across Instagram, TikTok, YouTube, Facebook, LinkedIn, and X with version control.
- **Real-Time Revenue Attribution**: End-to-end attribution linking creator posts directly to orders, CPA, ROAS, and net financial ROI.
- **Interactive Campaign ROI Forecaster**: Live revenue math engine calculating projected sales and order volume based on budget inputs.

## 🛠️ Local Development Setup

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/arefinMilen/creator-marketing-os.git
   cd creator-marketing-os
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 📦 Production Build

To test the production build locally:

```bash
npm run build
npm run start
```
